# 项目数据库工作台：第一批

支持 SQLite 和默认安装的 MySQL 驱动，范围为项目连接管理、结构浏览、只读查询、Agent 工具和本机命令行。SQL 写入和表结构变更尚未开放。

## 使用

1. 打开已绑定工作区的会话，点输入区“数据库”。
2. 填写连接名称和已有 SQLite 文件，或 MySQL 只读账号。保存配置不代表连接已测试；点“查看表结构”验证连接。
3. 使用 SELECT、WITH 或 EXPLAIN；结果最多200行，超限需缩小查询。SQLite 以只读方式打开并设置授权器、执行预算及单值大小限制。
4. Agent 的 database_connections、database_schema、database_query 经现有权限闸门确认后，共用查询服务。只向模型列出连接 ID、名称和类型。
5. 命令行示例见 README，支持用户名或本机用户 ID、绝对项目路径及 SQL 文件输入。项目路径统一标准化，避免符号路径别名导致查找不一致。

## 凭据和限制

配置与应用内部数据库分开保存在 data/database-connections.json，按应用用户和标准化项目路径隔离，密码不通过列表接口或 Agent 结果返回。文件0600权限保护，但不是加密存储。无浏览器端保存密码、无SQL日志功能。

启动器会自动安装 MySQL 驱动，服务器须支持只读事务与 MAX_EXECUTION_TIME。使用独立的最小权限只读账号，不应使用数据库管理员账号。已用隔离 MySQL 9.7.1 验证应用界面、API、Agent 和 CLI 查询，不宣称与所有版本或 MariaDB 兼容。

本批支持编辑连接（密码留空保留原密码），不提供写操作、导出、数据编辑或独立数据库凭据保险库。表列表和结构也受到结果行数上限约束，大库可自行查询系统目录分页。

## 可移植安装与 MySQL 联调

运行 `python3 start.py`（Windows 用 `py start.py`）自动创建项目环境、安装锁定的 PyMySQL 驱动及认证依赖。用户不需要安装 mysql 命令行工具或本机 MySQL 服务；填写已有服务器的连接信息即可。`share.sh` 也复用相同安装入口及项目 Python 环境。首次安装需要 Python 3.11+、网络和正常的包源证书。

新增测试连接、编辑现有配置、MySQL SHOW TABLES / DESCRIBE / SHOW INDEX、明确的认证/网络/SQL错误提示。查询达到200行后直接关闭一次性流式连接，避免继续拉取全部结果或驱动析构报错。

实库测试程序独立初始化临时 MySQL，使用专门只读账号，结束即关闭并删除；正常运行不使用该测试程序。干净代码副本使用项目独立环境启动，不读取原有配置和数据。

最终验证结果：后端897项、前端105项通过；MySQL 9.7.1 独立实例下，实际登录填写配置、测试连接、查询以及 API/Agent/CLI 联调通过；SQLite 连接编辑与手机布局回归通过。新建项目虚拟环境安装及无原配置/数据的干净副本启动验证通过。未在 Windows 真机或所有 MySQL 版本上验证。

## 项目优先与树形浏览

数据库面板不再依赖会话 ID：新任务选择项目后即可配置连接，未选项目时提供文件夹选择入口，不发送模型消息、不创建空会话。现有会话仍校验归属和项目，切换项目后拒绝旧连接请求。

左侧按连接、已配置数据库、表/视图展示，连接配置默认收起；支持表名搜索及每页100张表的目录分页。点击表后，右侧在字段结构和表数据之间切换；数据每页100行，存在主键时按主键排序。分页不是跨请求数据库快照，外部并发写入仍可能影响页面内容。任意SQL查询继续保持200行上限。

目录、字段和数据独立读取，避免所有表字段混合后被200行上限截断。SQL标识符先验证归属再按驱动规则引用，搜索和值采用参数化查询。迟到响应受项目、会话、登录身份和请求版本校验，不覆盖新视图。

验证：后端899项、前端105项通过；临时SQLite实际登录验证无会话项目配置、超过200张表的搜索与翻页、字段/数据切换和数据翻页；真实临时MySQL验证目录、单表字段和主键分页；已有会话连接编辑及手机布局回归通过。
