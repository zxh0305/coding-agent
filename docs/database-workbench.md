# 项目数据库工作台：第一批

支持 SQLite 和可选 MySQL 驱动，范围为项目连接管理、结构浏览、只读查询、Agent 工具和本机命令行。SQL 写入和表结构变更尚未开放。

## 使用

1. 打开已绑定工作区的会话，点输入区“数据库”。
2. 填写连接名称和已有 SQLite 文件，或 MySQL 只读账号。保存配置不代表连接已测试；点“查看表结构”验证连接。
3. 使用 SELECT、WITH 或 EXPLAIN；结果最多200行，超限需缩小查询。SQLite 以只读方式打开并设置授权器、执行预算及单值大小限制。
4. Agent 的 database_connections、database_schema、database_query 经现有权限闸门确认后，共用查询服务。只向模型列出连接 ID、名称和类型。
5. 命令行示例见 README，支持用户名或本机用户 ID、绝对项目路径及 SQL 文件输入。项目路径统一标准化，避免符号路径别名导致查找不一致。

## 凭据和限制

配置与应用内部数据库分开保存在 data/database-connections.json，按应用用户和标准化项目路径隔离，密码不通过列表接口或 Agent 结果返回。文件0600权限保护，但不是加密存储。无浏览器端保存密码、无SQL日志功能。

MySQL 需安装 pymysql，服务器须支持只读事务与 MAX_EXECUTION_TIME。使用独立的最小权限只读账号，不应使用数据库管理员账号。未进行真实 MySQL 实例联调，不宣称与所有版本或 MariaDB 兼容。

本批不提供连接配置编辑（可移除后重建）、写操作、导出、数据编辑或独立数据库凭据保险库。表列表和结构也受到结果行数上限约束，大库可自行查询系统目录分页。

## 验证

实际登录页面覆盖：保存连接、读取表结构、查询、拒绝写入及手机布局。测试使用隔离账号、项目、数据库，不连接真实业务库。
